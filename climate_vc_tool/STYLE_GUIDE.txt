1. DESIGN PHILOSOPHY

Core Concept: "Digital Journal"
- Warm, tactile feel of a physical notebook
- Hand-drawn imperfection (slight rotations, organic shapes)
- Paper texture and subtle grain
- Ink-based color palette (black ink, sepia tones, forest green accents)
- Friendly, approachable handwritten typography
- Analog decorative elements (doodles, tape, splatters)

Visual Principles:
- Organic over geometric
- Imperfect over perfect (slight rotations, wobbly lines)
- Warm over cool (cream paper, not white)
- Playful over corporate
- Handcrafted over digital

Color Usage Guidelines:
- Paper (#F5F1E8): Main background, always present
- Ink (#2C2C2C): All body text, headings, primary UI
- Ink-accent (#6B7A5C): Tech tags, secondary text, nature-themed accents
- Highlight (#C67B5C): Interactive elements (links, buttons, hover states)
- Fade (#8A8A8A): Timestamps, captions, less important text
- Line (#D4CFC4): Subtle borders, dividers, underlines
- Tape (rgba 30% opacity): Decorative washi tape overlays

9. ROTATIONS (Organic Imperfection)

Slight Rotations:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Tailwind Config:
```javascript
rotate: {
  '1': '1deg',
  '2': '2deg',
  '3': '3deg',
  '-1': '-1deg',
  '-2': '-2deg',
  '-3': '-3deg',
}
```

Usage Guidelines:
- Main content: rotate-1 or rotate--1 (subtle)
- Buttons/cards: rotate-2 (noticeable but not extreme)
- Decorative elements: rotate-3 (playful)
- Alternate rotations: nth-child(even) = positive, nth-child(odd) = negative

Example:
<div className="rotate-1 hover:rotate-0">
  <!-- Starts slightly tilted, straightens on hover -->
</div>
